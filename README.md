# Markdown Vault

Personal Markdown vault for notes, projects, meetings, tasks, and reusable knowledge.

## Folder Structure

- 00-Inbox: quick notes and temporary capture
- 01-Daily-Notes: daily work logs
- 02-Projects: active project notes
- 03-Areas: ongoing responsibility areas
- 04-Meetings: meeting notes
- 05-Knowledge: reusable technical and business notes
- 06-Templates: note templates
- 90-Archive: completed or inactive notes
- Attachments: images and supporting files
